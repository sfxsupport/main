All selected work

The problem

Learning Apex syntax and answering multiple-choice questions do not show whether a developer can implement a requirement against Salesforce. Forge gives learners a place to write and execute code.

What SFX built

A public challenge catalogue across Apex, Triggers, SOQL, and SOSL, with sign-in, Salesforce-connected execution, feedback, and progress tracking. The catalogue currently contains 129 challenges.

The user journey

  1. Browse the challenge catalogue and choose a track.
  2. Read a requirement and write an approach.
  3. Sign in and use the available Salesforce execution path.
  4. Review the runtime feedback and continue practising.

Relevant engineering work

The product brings together a coding interface, an authenticated user experience, Salesforce execution, and feedback linked to individual challenges. It provides a concrete starting point for discussing Salesforce-connected applications.

What this example establishes

Forge is a live SFX-owned product, not a paid customer case study. We have not published client ROI, a performance benchmark, or an independently verified success rate for this project.
