Set up

Two minutes, once.

The owner makes a private connector address in SFX and pastes it into Claude or ChatGPT.

  1. 1

    In SFX: Setup → AI connector

    Choose what it may do and click Make the connector. Copy the address; it is shown only once.

  2. 2

    In Claude: Settings → Connectors

    Add custom connector, name it SFX Travel Manager, paste the address. Switch it on in a chat from the tools button.

  3. 3

    Or in ChatGPT: Settings → Connectors

    In Developer mode choose Create, paste the address, authentication None.

  4. 4

    Ask

    "What are today's duties without a car?" Allow the tool the first time. That is all.
