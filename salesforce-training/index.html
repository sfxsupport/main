AI-first learning

Don't fear AI. Learn Salesforce with it.

Everyone is asking whether AI will take Salesforce jobs. You don't need to be scared of it. AI only feels like a threat when you try to compete with it. We learn with it instead: you use AI to understand errors, draft code and move faster, and you learn enough Salesforce to know when it is wrong. That is how we are growing, and how you will too.

When you fear AI

  • Stuck for hours on one error
  • Memorising syntax you can look up
  • Pasting AI code you can't explain
  • Worrying it will replace you

When you learn with AI, like we do

  • Ask AI to explain the error, then fix it yourself
  • Spend your time on design, data and security
  • Review and test every line AI writes
  • Build AI features with Agentforce and ClaudeForce

Syllabus

What we cover, in this order.

We start with Admin on purpose. Once you understand data, security and Flow, the code, integrations and AI parts make a lot more sense.

One connected curriculum

Admin → Development → Integrations → Agentforce & ClaudeForce → Portfolio

See the five projects ↓
  1. Phase 1

    Salesforce Admin

    Understand the platform before you code

    CRM fundamentals, data modelling, users, profiles, permission sets, sharing, validation rules, Flow, reports and dashboards.

  2. Phase 2

    Development

    Move from configuration to code

    Apex, SOQL, SOSL, triggers, test classes, asynchronous processing, Lightning Web Components and debugging patterns.

  3. Phase 3

    Integrations

    Connect Salesforce safely

    REST and SOAP APIs, OAuth, Named Credentials, callouts, webhooks, asynchronous designs, error handling and reconciliation.

  4. Phase 4

    Salesforce + AI

    Build useful agentic experiences

    Agentforce topics and actions, Flow and Apex orchestration, grounding, guardrails, human review and ClaudeForce workflows.

  5. Phase 5

    Projects & proof

    Turn learning into visible work

    Complete five guided projects, document decisions, receive review and build portfolio evidence through SFX Grove.
