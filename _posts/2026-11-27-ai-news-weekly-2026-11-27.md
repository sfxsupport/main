This issue covers announcements published from 20 November 2026 to 27 November 2026, inclusive.

## The week in 60 seconds
{: #week-in-60-seconds}

- **OpenAI:** `chat-latest` changed, and selected Responses API models gained healthcare configurations.
- **Anthropic:** Claude gained MCP features; Anthropic also published an API migration report and opened a safeguards beta.
- **Developer workflows:** Claude Ship introduced beta agents, and GitHub announced a Copilot billing change effective 30 December 2026.

## Models and API
{: #models-and-api}

### OpenAI updates `chat-latest`

**What:** On 24 November 2026, OpenAI updated the snapshot behind `chat-latest`. The alias will keep changing; OpenAI recommends the GPT-6.2 family for production API use.

**Why it matters / what to do:** Changed model behavior can affect Salesforce summaries and structured fields. Find calls using the alias and evaluate a production model against representative prompts.

**Source:** [OpenAI: API changelog](https://developers.openai.com/api/docs/changelog)

### OpenAI adds healthcare configurations

**What:** On 24 November 2026, OpenAI released healthcare configurations for selected Responses API models. Their web searches use an index of medical sources.

**Why it matters / what to do:** Health Cloud teams may want to assess evidence-finding uses. Start with synthetic cases in a sandbox and involve clinical and privacy owners in reviewing citations and data handling.

**Source:** [OpenAI: API changelog](https://developers.openai.com/api/docs/changelog)

### Anthropic explains its Messages API migration

**What:** On 25 November 2026, Anthropic published an account of moving its Messages API from Python to Rust. It reported lower CPU use and faster median time to first token, using shadowed production traffic to check differences.

**Why it matters / what to do:** The reported improvements do not predict performance for every integration. Measure your Salesforce workflow's latency and timeouts before changing service expectations.

**Source:** [Anthropic: Migrating our Messages API to Rust](https://www.anthropic.com/research/migrating-api-to-rust)

## MCP and trust
{: #mcp-and-trust}

### Claude expands MCP support

**What:** On 24 November 2026, Anthropic announced a public beta of Skills over MCP in Claude and Claude Code. Tasks and Elicitation are generally available; feature availability varies by plan.

**Why it matters / what to do:** Servers can provide guidance, handle longer jobs and request input. Check both client and server support before testing a read-only Salesforce workflow with scoped credentials.

**Source:** [Anthropic: MCP updates for Claude](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more)

### Anthropic opens a safeguards beta

**What:** On 23 November 2026, Anthropic announced a public beta of Enterprise Frontier Safeguards, combining misuse monitoring with customer-controlled storage compatible with zero data retention.

**Why it matters / what to do:** Eligible teams can assess it for Claude integrations. Map the full Salesforce data path with security owners and review eligibility, retention, access and storage costs.

**Source:** [Anthropic: Enterprise Frontier Safeguards beta](https://claude.com/resources/articles/zero-data-retention-with-enterprise-frontier-safeguards)

## Developer workflows
{: #developer-workflows}

### Claude Ship adds review and approval agents

**What:** On 23 November 2026, Anthropic introduced Claude Ship for Team and Enterprise GitHub repositories. It combines generally available Code Review with beta agents for pull request fixes and policy-based approvals.

**Why it matters / what to do:** Usage is billed on tokens, and the service can miss issues. Pilot a low-risk repository with spending limits, human review and approvals in observe mode. Check eligibility: zero data retention, HIPAA and customer-managed encryption key configurations are excluded.

**Source:** [Anthropic: Introducing Claude Ship](https://claude.com/resources/articles/introducing-claude-ship)

### GitHub changes a Copilot review billing default

**What:** On 25 November 2026, GitHub announced that, from 30 December 2026, affected Copilot Business and Enterprise accounts without a saved choice will default to organization billing for licensed members' code reviews. Existing choices remain; exceptions apply.

**Why it matters / what to do:** Organization spending could rise. Review the enterprise or organization Copilot policy and select Member before 30 December if member billing is intended.

**Source:** [GitHub: Copilot code review billing](https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization/)
