This issue covers announcements published from 20 November 2026 to 27 November 2026, inclusive.

## The week in 60 seconds
{: #week-in-60-seconds}

- **OpenAI:** `chat-latest` changed; check production integrations for a moving model alias.
- **Healthcare:** New Responses API configurations use a medical-source index when they search the web.
- **MCP:** Claude gains support for server-provided skills and longer-running, interactive tasks.
- **Claude:** Anthropic published API migration results and opened a zero data retention safeguards beta.
- **Developer costs:** Claude Ship enters beta, while a Copilot review billing default changes on 30 December.

## Models and API
{: #models-and-api}

### OpenAI updates `chat-latest`

**What happened:** On 24 November 2026, OpenAI updated the snapshot behind its `chat-latest` API model. The company says the underlying snapshot will change regularly and recommends the GPT-6.2 family for production API use.

**Why it matters for Salesforce teams:** A Salesforce callout using a moving alias can produce different answers or follow instructions differently after an update. That matters when a response feeds a case summary, a structured field, or an action that a user expects to behave consistently.

**What to do:** Inventory Salesforce callouts that use `chat-latest`; evaluate a suitable explicit production model and available snapshot against a saved set of representative prompts before switching.

**Source:** [OpenAI: API changelog](https://developers.openai.com/api/docs/changelog)

### OpenAI adds healthcare configurations to the Responses API

**What happened:** On 24 November 2026, OpenAI released healthcare configurations for selected models through the Responses API. They pair a model with a setup tailored to clinical questions; when the model uses web search, it searches a dedicated index of medical sources.

**Why it matters for Salesforce teams:** Health Cloud teams can evaluate the configurations for workflows that need medical evidence, such as helping a qualified reviewer find relevant sources. A cited response still needs verification, and the announcement does not by itself establish that a particular Salesforce data flow is approved for protected health information.

**What to do:** Run a sandbox evaluation with synthetic cases and have clinical and privacy owners review the answers, citations, data handling and intended use before considering real records.

**Source:** [OpenAI: API changelog](https://developers.openai.com/api/docs/changelog)

### Anthropic explains its Messages API migration

**What happened:** On 25 November 2026, Anthropic published an account of migrating the core Messages API from Python to Rust. It reports about 70% less CPU use per request and about 20% lower median time to first token, using comparisons against production traffic to help verify the migration.

**Why it matters for Salesforce teams:** Teams calling Claude directly may see a latency benefit, but Anthropic's median is not a promise for a particular Salesforce workflow. End-to-end time also includes the callout, network, model generation and any downstream processing; the article does not establish an Agentforce-wide improvement.

**What to do:** Measure current end-to-end latency and timeout rates for a representative Claude-backed workflow before changing any timeout or user-experience expectations.

**Source:** [Anthropic: Migrating our Messages API to Rust](https://www.anthropic.com/research/migrating-api-to-rust)

## MCP and trust
{: #mcp-and-trust}

### Claude expands MCP support for skills and tasks

**What happened:** On 24 November 2026, Anthropic announced a public beta of Skills over MCP in Claude and Claude Code, allowing servers to provide workflow guidance alongside tools. It also said Tasks and Elicitation are generally available in those clients for certain plans, with Team and Enterprise rollout varying; file uploads were described as coming soon.

**Why it matters for Salesforce teams:** A compatible MCP server could provide instructions for a multi-step CRM workflow, run longer work, or ask for user input before an action. These are capabilities of the specified clients and server implementations: the announcement does not establish that every Agentforce connection supports them.

**What to do:** In a sandbox, check your chosen client's support and test one read-only MCP workflow with scoped credentials before exposing any record-changing tool.

**Source:** [Anthropic: MCP servers can now ship skills, run tasks, and more with Claude](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more)

### Anthropic opens a zero data retention safeguards beta

**What happened:** On 23 November 2026, Anthropic opened Enterprise Frontier Safeguards to public beta. Its design combines automated monitoring across requests with customer-controlled storage for inputs and outputs; safety cases can be reviewed from cloud storage or through an API.

**Why it matters for Salesforce teams:** This gives eligible buyers a data-handling option to assess for direct Claude integrations. It does not mean inputs and outputs disappear entirely: customers supply storage and control access, so Salesforce records, logs, integrations and provider settings all remain part of the review.

**What to do:** Ask your security team to map the full data path and confirm eligibility, storage costs, retention settings and access controls for the intended deployment.

**Source:** [Anthropic: Zero data retention with Enterprise Frontier Safeguards is now in beta](https://claude.com/resources/articles/zero-data-retention-with-enterprise-frontier-safeguards)

## Developer workflows
{: #developer-workflows}

### Claude Ship brings review and approval agents to GitHub

**What happened:** On 23 November 2026, Anthropic introduced Claude Ship in beta for Claude Team and Enterprise organizations using GitHub. It combines the existing Code Review product with beta agents for working on pull request feedback and applying a team-written approval policy.

**Why it matters for Salesforce teams:** Teams maintaining Apex, Lightning Web Components and metadata in GitHub can test it as part of their review process. Usage is billed on tokens, the agents can miss issues, and the product is unavailable to organizations using certain configurations, including zero data retention and HIPAA configurations.

**What to do:** Pilot one low-risk repository with an approval policy in observe-only mode, a spend limit and existing human review and deployment checks.

**Source:** [Anthropic: Introducing Claude Ship](https://claude.com/resources/articles/introducing-claude-ship)

### GitHub sets a new Copilot review billing default

**What happened:** On 25 November 2026, GitHub announced that, from 30 December 2026, Copilot code reviews by licensed members will default to organization billing when an affected organization has no saved choice. Existing Member or Organization choices stay in effect, and GitHub lists exceptions for accounts without the necessary paid usage or billing setup.

**Why it matters for Salesforce teams:** A team reviewing Salesforce code in a GitHub organization could see review costs move from members' entitlements to the organization. This is a billing policy change, so repository owners should coordinate with the person who controls the organization or enterprise setting.

**What to do:** Check the Copilot code review billing policy before 30 December and explicitly select Member if that is the intended arrangement.

**Source:** [GitHub: Copilot code review billing will default to the organization](https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization/)
