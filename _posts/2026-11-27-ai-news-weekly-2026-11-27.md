This issue covers announcements published from 20 November 2026 to 27 November 2026, inclusive.

## The week in 60 seconds
{: #week-in-60-seconds}

- **OpenAI:** The `chat-latest` snapshot changed, and healthcare configurations arrived in the Responses API.
- **MCP:** Claude added support for server-provided skills, long-running tasks and requests for user input.
- **Anthropic:** An API migration report and a data safeguards beta offer lessons for integration teams.
- **Developer workflows:** Claude Ship is in beta. A Copilot review billing default changes on 30 December 2026.

## Models and API
{: #models-and-api}

### OpenAI updates `chat-latest`

**What happened:** On 24 November 2026, OpenAI updated `chat-latest` and recommended the GPT-6.2 family for production API use. The alias will continue to change.

**Why it matters for Salesforce teams:** An alias update can change responses used in summaries or structured fields.

**What to do:** Find callouts using `chat-latest` and evaluate an explicit production model against representative prompts.

**Source:** [OpenAI: API changelog](https://developers.openai.com/api/docs/changelog)

### OpenAI adds healthcare configurations to the Responses API

**What happened:** On 24 November 2026, OpenAI added healthcare configurations for selected Responses API models, with a medical index for web searches.

**Why it matters for Salesforce teams:** Health Cloud teams can assess the configurations for evidence-finding workflows, but citations and data handling still need review.

**What to do:** Evaluate synthetic cases in a sandbox with clinical and privacy owners before considering real records.

**Source:** [OpenAI: API changelog](https://developers.openai.com/api/docs/changelog)

### Anthropic explains its Messages API migration

**What happened:** On 25 November 2026, Anthropic described moving its Messages API from Python to Rust. It reported lower CPU use and faster median time to first token, and used shadowed production traffic to check the migration.

**Why it matters for Salesforce teams:** The reported results do not establish how much faster a particular Salesforce integration will be.

**What to do:** Measure end-to-end latency and timeouts before changing expectations or settings.

**Source:** [Anthropic: Migrating our Messages API to Rust](https://www.anthropic.com/research/migrating-api-to-rust)

## MCP and trust
{: #mcp-and-trust}

### Claude expands MCP support for skills and tasks

**What happened:** On 24 November 2026, Anthropic announced Skills over MCP in public beta for Claude and Claude Code. Tasks and Elicitation are generally available for Pro, Max and Ultra, with Team and Enterprise rollout underway. Skills availability also varies by plan.

**Why it matters for Salesforce teams:** Compatible servers can offer workflow guidance, run longer jobs and request input. The announcement does not establish support in every Agentforce connection.

**What to do:** Check client and server support, then test a read-only workflow with scoped credentials in a sandbox.

**Source:** [Anthropic: MCP servers can now ship skills, run tasks, and more with Claude](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more)

### Anthropic opens a zero data retention safeguards beta

**What happened:** On 23 November 2026, Anthropic opened Enterprise Frontier Safeguards to public beta, combining misuse monitoring with customer-controlled storage.

**Why it matters for Salesforce teams:** Eligible teams can assess the option for direct Claude integrations, but customer storage and the wider Salesforce data path still need controls.

**What to do:** Map the data path with security owners and check eligibility, retention, access and storage costs.

**Source:** [Anthropic: Zero data retention with Enterprise Frontier Safeguards is now in beta](https://claude.com/resources/articles/zero-data-retention-with-enterprise-frontier-safeguards)

## Developer workflows
{: #developer-workflows}

### Claude Ship brings review and approval agents to GitHub

**What happened:** On 23 November 2026, Anthropic introduced Claude Ship for Team and Enterprise GitHub repositories. It combines existing Code Review with beta agents for pull request fixes and policy-based approvals.

**Why it matters for Salesforce teams:** Teams can assess it for Salesforce code, but usage is billed on tokens and the agents can miss issues. Claude Ship is unavailable for zero data retention, HIPAA and customer-managed encryption key configurations.

**What to do:** Pilot a low-risk repository with a spend limit, human review and approvals in observe-only mode.

**Source:** [Anthropic: Introducing Claude Ship](https://claude.com/resources/articles/introducing-claude-ship)

### GitHub sets a new Copilot review billing default

**What happened:** On 25 November 2026, GitHub announced that affected Copilot Business and Enterprise accounts without a saved billing choice will default to organization billing for licensed members' code reviews from 30 December 2026. Existing choices remain in effect; exceptions apply.

**Why it matters for Salesforce teams:** Organizations reviewing Salesforce code could incur additional charges.

**What to do:** Check the organization or enterprise Copilot policy before 30 December 2026 and select Member if member billing is intended.

**Source:** [GitHub: Copilot code review billing will default to the organization](https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization/)
