From 20 November 2026 to 27 November 2026, inclusive, OpenAI changed an API model alias, Claude picked up new integration tools, and GitHub set a date for a Copilot billing change. Here is what Salesforce teams should check.

## Models and APIs

### OpenAI updates `chat-latest`

**The change:** On 24 November 2026, OpenAI updated the snapshot behind `chat-latest`. The alias will keep changing, and OpenAI recommends the GPT-6.2 family for production API use.

Different model behavior can affect Salesforce summaries and structured fields.

**Do this:** Find calls using the alias and evaluate a production model and available snapshot against representative prompts before switching.

Source: [OpenAI: API changelog](https://developers.openai.com/api/docs/changelog)

### OpenAI adds healthcare configurations

**The change:** On 24 November 2026, OpenAI released healthcare configurations for selected Responses API models. Their web searches use an index of medical sources, which Health Cloud teams may want to assess for finding evidence.

**Do this:** Start with synthetic cases in a sandbox, and ask clinical and privacy owners to review citations and data handling.

Source: [OpenAI: API changelog](https://developers.openai.com/api/docs/changelog)

### Anthropic moves its Messages API to Rust

**The change:** On 25 November 2026, Anthropic published an account of moving its Messages API from Python to Rust. It reported lower CPU use and faster median time to first token—the time before a response starts—and checked differences using shadowed production traffic.

**Our read:** Those results do not predict performance for every integration.

**Do this:** Measure your Salesforce workflow's latency and timeouts before changing service expectations.

Source: [Anthropic: Migrating our Messages API to Rust](https://www.anthropic.com/research/migrating-api-to-rust)

## MCP and data controls

### Claude expands MCP support

**The change:** On 24 November 2026, Anthropic announced a public beta of Skills over MCP in Claude and Claude Code. MCP is a way for AI tools to connect to external systems; the features let servers provide guidance, handle longer jobs and request input.

Tasks and Elicitation are generally available, though feature availability varies by plan. The announcement covers Claude and Claude Code.

**Do this:** Before relying on these features in another MCP client, confirm that client supports them, then test a read-only Salesforce workflow with scoped credentials.

Source: [Anthropic: MCP updates for Claude](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more)

### Anthropic opens safeguards beta

**The change:** On 23 November 2026, Anthropic announced a public beta of Enterprise Frontier Safeguards. It combines misuse monitoring with customer-controlled storage compatible with zero data retention.

Eligible teams can assess it for Claude integrations, but customer-controlled storage does not mean the Salesforce team stores no data.

**Do this:** Map the full Salesforce-to-provider data path with security owners, and review eligibility, retention, access, encryption and storage costs.

Source: [Anthropic: Enterprise Frontier Safeguards beta](https://claude.com/resources/articles/zero-data-retention-with-enterprise-frontier-safeguards)

## Developer workflows

### Claude Ship adds review and approval agents

**The change:** On 23 November 2026, Anthropic introduced Claude Ship for Team and Enterprise GitHub repositories. It combines generally available Code Review with beta agents for pull request fixes and policy-based approvals.

Usage is billed on tokens, and the service can miss issues. Zero data retention, HIPAA and customer-managed encryption key configurations are excluded.

**Do this:** Check eligibility, then pilot a low-risk repository with spending limits, human review and approvals in observe mode.

Source: [Anthropic: Introducing Claude Ship](https://claude.com/resources/articles/introducing-claude-ship)

### GitHub changes Copilot review billing default

**The change:** On 25 November 2026, GitHub announced that, from 30 December 2026, affected Copilot Business and Enterprise accounts without a saved choice will default to organization billing for licensed members' code reviews. Existing choices remain in effect, and exceptions apply.

Organization spending could rise if the default applies.

**Do this:** Review the enterprise or organization Copilot policy and select Member before 30 December if member billing is intended.

Source: [GitHub: Copilot code review billing](https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization/)
