How Agentforce pricing works

Salesforce sells Agentforce in three ways. You can mix them: many orgs use Flex Credits or per-conversation pricing for a customer-facing agent and per-user add-ons for employees.

The break-even point

A conversation costs $2 on per-conversation pricing. On Flex Credits it costs the number of actions × $0.10. The two are equal at 20 text actions per conversation. If your agent runs fewer actions than that per conversation, Flex Credits cost less; if it runs more, per-conversation pricing costs less. Because one org cannot use both, also count employee usage: in a Conversations org employees need the per-user add-on. For employees, the $150 add-on equals Flex Credits at 1,500 text actions per user per month, before any separately billed prompt usage.

Worked example

5,000 customer conversations a month with 4 actions each is 20,000 actions × 20 credits = 400,000 Flex Credits. At $500 per 100,000 that is $2,000 a month. The same 5,000 conversations at $2 each would be $10,000 a month.

What the calculator leaves out

  • Negotiated discounts and minimum purchase amounts on your order form.
  • Data 360 (Data Cloud) credits for ingestion, indexing and retrieval, unless you enter them.
  • Salesforce edition and licence prerequisites. Agent Builder is available in Enterprise, Performance, Unlimited and Developer Editions; required add-on licences vary by agent type.
  • Prompt and generative usage that runs outside agent actions can be billed separately for some products (see the rate card); this calculator does not model it.
  • Billing models outside action metering, such as Help Agent per-resolution billing or login and member licences. In qualifying resolved Help Agent sessions, actions are bundled and are not billed one by one.
  • Actions that fail and are retried, and agent loops that run more actions than planned. Test with real transcripts before you commit to a volume.

How to keep Agentforce cost down

  1. Count actions, not conversations. On Flex Credits every action is billed. Merge small lookups into one Apex or Flow action that returns everything the agent needs.
  2. Keep topics narrow. Clear topic instructions and fewer, well-described actions stop the planner from calling actions it does not need.
  3. Test in a sandbox first. Sandbox actions use 16 credits instead of 20. Run your agent against real customer questions there and count the actions each conversation triggers before you pick a pricing model.
  4. Watch the Digital Wallet. Open Digital Wallet from the App Launcher in your production org and check consumption weekly in the first month.

Questions people ask

How much does one Agentforce action cost?

The Flex Credits rate card (November 2026) lists 20 credits per standard or custom action in production, 16 in sandbox, and 30 per voice action. At $500 per 100,000 credits, one text action is $0.10 and one voice action is $0.15.

Is Flex Credits or $2 per conversation cheaper?

They cost the same at 20 text actions per conversation. With fewer actions Flex Credits cost less; with more, per-conversation pricing costs less. Included credits and discounts move this point.

Can I use Flex Credits and per-conversation pricing in the same org?

No. Salesforce's pricing FAQ says Flex Credits and Conversations are not supported in the same org, so choose one model per org.

What does the Agentforce per-user add-on cost?

The Agentforce add-ons for Sales, Service and Field Service are listed at $150 per user per month, billed annually, and $175 for Industries clouds. Max Edition (formerly Agentforce 1) starts at $550 per user per month. Prompt usage outside agent actions can be billed separately for some products; check the rate card.

Does Data Cloud grounding cost extra?

It can. Data Library indexing and retrieval consume credits from either the Data Services or the Flex Credits consumption card, depending on your contract.

Do Enterprise orgs get free Flex Credits?

Salesforce Help says Enterprise Edition and above can get 100,000 Flex Credits with Salesforce Foundations, and current Sales pricing lists larger per-org amounts for some editions. Check your order form for the amount and term.
