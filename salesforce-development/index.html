Before we start

A few useful answers.

How is a project priced?

We review scope and acceptance criteria before quoting. A bounded task can be quoted at a fixed price; an uncertain issue may need a separately agreed paid diagnostic. No price or delivery date is committed before review.

Who will own the work?

Speak with Krrish Joshi about the requirement. Your proposal identifies the delivery owner, communication process, and review responsibilities. Agree any additional contributors before work starts.

What is included in the handover?

The agreed deliverables, relevant tests and test results, release notes, and operating guidance for the change. Deployment and ongoing support are specified in the proposal.

Do you need production access?

Initial scoping can use a description, redacted error details, and a call. Any later access is agreed for the work. Implementation and validation should use an appropriate sandbox or development environment before a production release.

Can we see previous work?

Yes. Our work page contains SFX-owned products, clearly labelled as internal work. We can discuss the parts relevant to your requirement without representing those products as client engagements.
